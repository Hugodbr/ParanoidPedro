# ¿Qué es Paranoid Pedro?
Paranoid Pedro es proyecto es un trabajo universitario, desarrollado por Telmo Kissoca Bailán y Hugo de Brito Rocha para la Universidad Complutense de Madrid, como evaluación para la asignatura *Programación de Videojuegos en Lenguajes Interpretados* (PVLI) en el [Grado en Desarrollo de Videojuegos](https://www.ucm.es/data/cont/docs/titulaciones/1913.pdf).

# Descripción general del proyecto
El proyecto consiste en un videojuego web desarrollado en javascript, bautizado como *Paranoid Pedro*, un juego plataformas inspirado en la época de la pandemia de 2020 y la cantidad de memes y bulos creados durante dicho momento histórico ya. Para desarrollar el juego hemos hecho nuestros propios tiles y sprites utilizando *Krita*, es posible encontrar los archivos .kra con los que hemos diseñado en la carpeta de *design*. Lo que nos resulta más interesante en cuanto a la implementación es el sistema de visibilidad de zonas, el sistema de 3D falso y el uso de árboles de comportamiento para la inteligencia artificial de los enemigos, de todo este tema se puede encontrar más información en el archivo *DGG.md*.
